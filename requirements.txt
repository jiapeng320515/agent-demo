# ============================================================================
# 核心运行依赖：零第三方库（仅 Python 标准库）
# ============================================================================
# 本项目刻意不引入任何第三方依赖，只用标准库（urllib / json / pathlib /
# math / time 等）从零理解 agent 机制，因此「核心运行时」无需安装任何包：
#
#     pip install -r requirements.txt      # 不会安装任何东西 —— 这是预期行为
#
# 唯一要求是 Python 版本 >= 3.12（推荐 3.12.x，见 ENVIRONMENT.md）。
#
# 阶段二（向量检索 / PDF / EPUB 解析）、阶段三（可选上框架）会用到
# 第三方库，这些「可选依赖」单独放在 requirements-optional.txt，
# 到对应阶段再安装即可：
#
#     pip install -r requirements-optional.txt
# ============================================================================
